# In-game copy style

Names identify the object. Item, fluid and building descriptions explain material,
construction, function, compatibility or an operational consequence. They are not
release notes, user-request acknowledgments, authoring commentary or sales copy.

- Prefer: "Ten copper-jacketed cartridges for automatic weapons and sentry turrets."
- Avoid availability commentary such as "now craftable from the beginning".
- Keep version comparisons and implementation limitations in documentation or release notes.
- Guides may explain progression and controls. Settings may explain the option they change.
- Do not use Unicode em dash or en dash punctuation in in-game or GitHub-facing text.
  Use a period, colon, parentheses, a comma or an ordinary hyphen instead.
- Localization generation and repository-text tests enforce the punctuation rule.

Published commit history is not rewritten. Current source text and editable release
metadata use this style; third-party/user-authored historical comments are not edited.
