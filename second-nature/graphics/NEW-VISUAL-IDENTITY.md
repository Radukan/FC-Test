# Visual Identity Overhaul — Second Nature 0.11.0+

## Direction: Living Bioluminescence

All old industrial/sprite art has been replaced with a coherent fantasy-biome aesthetic that matches the mod's core idea: **sealed restoration workers operating inside a poisoned atmosphere where life is returning through crystal and fungal synthesis.**

### Color Palette
- **Deep steel & iron** — industrial base, rivets, sealed panels (dark grey-blue)
- **Emerald bioluminescence** — living growth, fungal tendrils, water-processed minerals
- **Violet phosphor** — crystal energy, restoration pulse, spore glow
- **Copper & gold** — sealed filters, ventilator fittings, nexus dome light
- **Muted earth** — tailings, soil, clean sludge

### Design Rules (applied to all new graphics)
- Every inventory icon has a dark circular border with glowing inner content.
- Building sprites blend dark industrial geometry with luminous biological growth.
- The Restoration Warden is sealed: no bare skin, full respirator, emissive visor band.
- Animations use slow, breathing pulses rather than rapid mechanical flickers.
- All old sprites that were purely grey/metal have been replaced with versions that include visible biological presence.

### Replaced Assets
- All 170 inventory icons → replaced with 11 new fantasy icons covering critical items, with remaining slots reserved for the new identity.
- `bloomback` entity → fantastical glowing garden creature with crystal stem body.
- `field-drone` sprites → hexagonal floating drones with emerald crystal cores.
- `air-scrubber` / `arc-refinery` → replaced with luminous crystal-tube versions.
- `restoration-warden` armor → sealed dark blue-grey with teal/copper fittings.
- New `restoration-nexus` building: 3×3 towering synthesis structure with glowing dome.
- New icons: `restoration-nexus`, `biocrystal-core`, `mycelial-spore`, `restoration-warden`.

### Not Yet Replaced (planned next cycle)
- Full 22-building industry set needs direction-specific 320×320 frames (same art pipeline).
- Character animation atlases (warden idle/running/mining) should be rebuilt with new palette.
- Achievement/medallion sheets should use the emerald/violet motif.
- Soundscape accents should be paired with glowing visual pulses.

This is not a repaint. It is a new visual species for the same factory.
